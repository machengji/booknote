# 文献题录采集与清洗入库系统 —— 验收标准（对应验收报告）

## 1. 功能验收

| 编号 | 验收项 | 通过标准 | 验证方式 |
|------|--------|----------|----------|
| F-01 | WoS 日增量采集 | 每日 07:00 自动运行，state last_done 推进到昨日 | 查 state + 日志 |
| F-02 | Scopus 日增量采集 | 每日 07:20 自动运行，state last_done 推进到昨日 | 查 state + 日志 |
| F-03 | 超 5000 窗口拆分 | 单日 >5000 的日期可拆尽采尽，分桶求和与 total 一致（误差<10% 告警） | 查 issn-sum 日志 |
| F-04 | 去重 | 同一 UT/EID 在表中仅一行 | 主键约束 + 计数比对 |
| F-05 | 幂等重跑 | 重复导入不产生重复行，只刷新易变字段 | 重跑前后 COUNT(*) 不变 |
| F-06 | 跨库关联 | 两表可按 doi JOIN，WoS 覆盖≥95%，Scopus 覆盖≥85% | 抽样查询 |
