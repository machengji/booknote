# 文献题录采集与清洗入库系统 —— 产品介绍（评审第 6、7 项）

## 1. 产品概述

本产品面向科研文献数据团队，每日自动采集 Web of Science 与 Scopus 两大文摘库的新增
题录，经清洗对齐后存入关系型数据库，为文献检索、计量统计与知识图谱提供原始数据。
截至 2026-09-16，9 月单月已采集 WoS 49,865 条、Scopus 204,597 条。

## 2. 产品结构

```text
┌─────────────┐   ┌──────────────┐   ┌───────────────┐   ┌────────────┐
│  采集层      │──▶│  原始层       │──▶│  清洗入库层    │──▶│  应用层     │
│ harvest/    │   │  JSONL(WORM) │   │  MySQL宽/窄表  │   │ 检索·统计  │
└─────────────┘   └──────────────┘   └───────────────┘   └────────────┘
```

### 2.1 采集层（booknote/harvest）

| 模块 | 功能 | 输入 | 输出 |
|------|------|------|------|
| wos_pipeline.py | WoS 日增量采集：会话复用、上大代理落地、按出版日检索、xls 导出解析 | 待采日期 | wos_YYYY-MM.jsonl + scihuber_state.json |
| scopus_pipeline.py | Scopus 日增量采集：三入口落地、ORIG-LOAD-DATE 窗口、网关分页 | 待采日期 | scopus_YYYY-MM.jsonl + scopus_state.json |
| issn_buckets.py | 离线 ISSN 分桶：官方来源表生成 187 桶×400 ISSN，破 5000 窗口 | 来源表 xlsx | scopus_issn_buckets.json |
| daily.py | 每日调度：读水位、串行跑两库、日间间隔防封 | 无（自动算日期） | 两库当日增量 |
| wos_to_mysql.py / scopus_to_mysql.py | 批量入库，幂等 | JSONL | MySQL 表 |

### 2.2 原始层（JSONL，只追加不修改）

- WoS：44 个实采字段（摘要、作者全名、刊名、ISSN、被引、关键词等），约 209MB/月。
- Scopus：11 个字段（eid、doi、标题、年、刊名、issn、被引、作者等），约 70MB/月。
- 两库以 `doi` 为关联键（WoS 覆盖 97.9%，Scopus 覆盖 87.8%）。

### 2.3 清洗入库层（MySQL booknote 库）

- `wos_records`：66 列宽表，主键 ut_unique_wos_id，索引 doi/年份/刊名/pubmed。
- `scopus_records`：11 列窄表，主键 eid，索引 doi/年份/刊名/采集日。
- 重复导入幂等：只刷新被引数、使用量等易变字段。

### 2.4 应用层

基于两表提供按年/刊/作者/关键词的计数统计、DOI 跨库关联查询、
每日对账（按天分组计数与 state 水位比对）。
